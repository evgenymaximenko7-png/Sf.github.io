# Экран ТВ

Статическая страница отображения для GitHub Pages. Диспетчерская остаётся на локальном компьютере.

Откройте страницу на ТВ и введите показанный код tv-… в поле «Код с экрана ТВ» у диспетчера. Нажмите «Связать с ТВ». Используется исходный протокол, без дополнительных префиксов и фильтров сообщений.

В репозитории нет базы транспорта, телефонов, бэкапов и пароля диспетчера. Данные поступают непосредственно из открытой диспетчерской через WebRTC.

Публикация: Settings → Pages → Deploy from a branch → main → / (root) → Save.

PeerJS 1.5.2: MIT, https://github.com/peers/peerjs. Библиотека раздаётся вместе со страницей.

Репозиторий: https://github.com/evgenymaximenko7-png/Sf.github.io
